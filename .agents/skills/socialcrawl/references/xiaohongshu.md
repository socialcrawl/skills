# Xiaohongshu

6 endpoints, all GET. Base URL `https://www.socialcrawl.dev`, auth header `x-api-key: $SOCIALCRAWL_API_KEY`.

**Credit costs:** 2 advanced (5), 4 custom (flat/metered) - the exact cost is in each endpoint heading below.

Xiaohongshu (RedNote), the Chinese lifestyle network. It is not Douyin and not TikTok: separate creators, notes and trends. Keyword search, the hot search board, a creator profile, that creator's notes, one note, and top level comments. Search and creator-note rows carry a short summary in post.content.text with post.ext.text_truncated set; the note endpoint returns the body. There is no view count, so post.engagement.views is null. List lanes are METERED at 5 credits a row returned, so cap limit and read credits_used.
